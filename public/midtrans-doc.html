4. Alur Transaksi Pemesanan & Pembayaran (Step-by-Step)
1
Pengguna Membuka Web App & Melakukan Login
Pengguna mengakses https://www.kancasela.my.id/ melalui browser. Pengguna masuk dengan akun email/Google SSO agar data langganan tersinkronisasi ke profil.
[Header KancaSela] -> [Tombol: 👤 Masuk / Profil] -> [Form Login Email & Password / 🌐 Google 1-Tap]
2
Mengakses Menu Paket Langganan (Kanca Tiers)
Pengguna mengklik tombol "Lihat Pro →" pada banner iklan atau memilih menu "💎 Kanca Tiers" di profil.
[Modal Pricing Terbuka] -> Tampilan Toggle: [Bulanan] / [Tahunan (Hemat 45%)]
Katalog: [Kanca Bebas (Rp 0)] | [Kanca Pro (Rp 19.000/bln)] | [Kanca Warkop (Rp 149.000/bln)]
3
Memilih Paket & Menginisiasi Checkout
Pengguna menekan tombol "🚀 Upgrade ke Kanca Pro". Sistem mengirimkan request ke backend untuk membuat token transaksi Midtrans Snap.
POST /functions/v1/create-midtrans-payment
Payload: { orderId: "KANCA-PRO-XXXX", grossAmount: 19000, userEmail: "reviewer@kancasela.my.id" }
Response: { token: "SNAP-TOKEN-XXXX" }
4
Popup Pembayaran Midtrans Snap Terbuka
Popup Midtrans Snap secara resmi muncul di layar. Pengguna memilih metode pembayaran yang diinginkan (QRIS, GoPay, ShopeePay, Virtual Account BCA/Mandiri/BNI/BRI, atau Kartu Kredit).
[Pop-up Midtrans Snap UI]
Total Pembayaran: Rp 19.000
Opsi: 📱 QRIS (GoPay/OVO/Dana) | 🏦 Virtual Account | 💳 Kartu Kredit/Debit
5
Notifikasi Webhook & Aktivasi Akun Instan (Fulfillment)
Setelah pembayaran diselesaikan oleh pengguna, Midtrans mengirimkan notifikasi HTTP Webhook status settlement. Server KancaSela memvalidasi signature key dan mengaktifkan status Pro pada akun secara otomatis (< 3 detik). Iklan langsung hilang seketika.
Webhook Trigger: transaction_status = "settlement" -> Verify SHA512 Signature
Database Update: profiles SET is_pro = true, subscription_tier = 'pro'
Result UI: Pop-up "🎉 Selamat! Akun Kanca Pro Anda Telah Aktif."
